# Zed 단축키 모음

지금까지 학습 기록에 나온 키. **Mac · Vim 모드 기준**이며, 기본 키는 Zed 1.26.2에서 확인한 기록을 바탕으로 정리했다. 새 버전에서는 달라질 수 있다.

- `g r n`처럼 띄어 쓴 키는 **차례대로**, `Cmd+P`는 **동시에** 누른다.
- Vim 키는 영문 입력 + 일반 모드(`Esc`)에서 사용한다.
- **설명만**은 직접 실습·동작 확인을 끝내지 않은 항목이다.
- `Space` 키는 LazyVim과 달리 기본 리더가 아니다. 아래 사용자 키맵 참고.

## 열기·탭·명령

| 키 / 명령 | 용도 | LazyVim 대응 / 메모 |
|---|---|---|
| 터미널에서 `zed .` | 현재 폴더 열기 | 셸 명령 |
| `Cmd+Shift+P` | 명령 팔레트: 이름으로 명령 찾기 | 키가 기억 안 나면 여기서 검색 |
| `Cmd+P` | 파일 찾기 | `Space Space` |
| `:e <경로>` | 파일 열기 | 같음 |
| `] b` / `[ b` | 다음 / 이전 탭 | 같음. 복습 필요 |
| `:ls` | 열린 탭 목록 | Zed에서는 탭 전환 목록 표시. `Ctrl+Tab`도 안내함 |
| `Ctrl+1` ~ `Ctrl+9` | 탭 번호로 이동 | LazyVim 기본 매핑 없음 |
| `Ctrl+o` / `Ctrl+i` | 이동 기록 뒤로 / 앞으로 | 같음 |
| `:w` / `:q` / `:wq` | 저장 / 닫기 / 저장 후 닫기 | 같음 |
| `Cmd+O` | 폴더 열기 | 프로젝트 열기 안내 |
| `Alt+Cmd+O` / `Ctrl+R` | 최근 프로젝트 목록 | 목록에서 프로젝트 선택 |
| `Cmd+Shift+A` | 최근 프로젝트 목록에서 폴더 추가 | **최근 프로젝트 목록 안에서** 사용 |
| `Cmd+Shift+Enter` | 선택한 프로젝트를 현재 워크스페이스에 추가 | **최근 프로젝트 목록 안에서** 사용 |
| `Cmd+Shift+N` | 새 창 | window = 창 |
| 팔레트 `add folder to project` | 현재 프로젝트에 폴더 추가 | 여러 루트 폴더 함께 열기 |

## 분할·패널·탭 닫기

pane은 편집기 분할 영역, dock은 패널이 붙는 영역이다.

| 키 / 명령 | 용도 | LazyVim 대응 / 메모 |
|---|---|---|
| `Ctrl+w v` / `:vs` | 좌우 분할 | `Ctrl+w v` 또는 `Space \|`. Zed는 `Cmd+\`도 가능 |
| `Ctrl+w s` / `:sp` | 위아래 분할 | `Ctrl+w s` 또는 `Space -` |
| `Ctrl+w h/j/k/l` | 왼쪽 / 아래 / 위 / 오른쪽 pane으로 이동 | 같음 |
| `Ctrl+w o` | 다른 pane 닫기 | 같음. 남는 탭 상태는 확인 미완료 |
| `Cmd+B` | 왼쪽 dock 토글 | 프로젝트 트리를 여닫는 용도로 LazyVim `Space e`와 비교 |
| `Cmd+Shift+E` | 프로젝트 패널로 이동, 현재 파일 위치 표시 | LazyVim `Space e` |
| 패널에서 `Esc` | 편집기로 복귀 | 패널 포커스일 때 |
| 패널에서 `j` / `k` | 항목 아래 / 위 이동 | Vim 방식 |
| `Cmd+J` | 아래 dock 토글 | 설명만 |
| `Cmd+W` | 현재 탭 닫기 | 설명만 |
| `Alt+Cmd+T` | 다른 탭 닫기 | 설명만 |
| `Cmd+Shift+T` | 닫은 탭 다시 열기 | 설명만 |

### 프로젝트 패널 전용 — 설명만

| 키 | 용도 | 주의 |
|---|---|---|
| `%` | 새 파일 | 편집기 안의 Vim `%`와 문맥이 다름 |
| `d` | 새 폴더 | **LazyVim 파일 트리의 `d`는 삭제**라 혼동 주의 |
| `Shift+R` | 이름 바꾸기 | 프로젝트 패널에서 사용 |
| `Shift+D` | 삭제 | 프로젝트 패널에서 사용 |

## 코드 탐색·수정 (LSP)

| 키 | 용도 | LazyVim 대응 / 메모 |
|---|---|---|
| `g d` | 정의로 이동 | 같음 |
| `g r r` / `g A` | 참조 찾기 | LazyVim `g r` |
| `K` | 타입·문서 hover | 같음 |
| `g r n` | 심볼 이름 바꾸기 | LazyVim `Space c r`. `price_of` 5곳 변경 실습 완료 |
| `g .` / `g r a` | 코드 액션 | LazyVim `Space c a`. `new` 생성 실습 완료 |
| `] d` / `[ d` | 다음 / 이전 진단 | 같음 |
| `g s` | 현재 파일 심볼 찾기 | LazyVim `Space s s`. Zed `Cmd+Shift+O`도 가능. 설명만 |
| `g S` | 프로젝트 심볼 찾기 | Zed `Cmd+T`도 가능 |
| `Ctrl+w d` | 정의를 분할로 열기 | Zed의 Vim 확장 |
| `Cmd+Shift+M` | 진단 패널 | LazyVim `Space x x` |

LazyVim의 `g r`은 바로 실행되는 매핑이라 Zed의 `g r n`·`g r r`을 그대로 쓸 수 없다.

## 멀티커서·검색·멀티버퍼

| 키 / 명령 | 용도 | LazyVim 대응 / 학습 상태 |
|---|---|---|
| `g a` | 같은 단어 전부 선택 | Zed `Cmd+Shift+L`도 가능. `mocha` → `tea` 5곳 실습 완료 |
| 선택 후 `c` → 입력 → `Esc` | 선택한 곳을 한꺼번에 변경 | Vim 편집 동작 사용 |
| `g l` | 다음 일치를 선택에 추가 | Zed `Cmd+D`도 가능. 설명만 |
| `g >` | 현재 일치를 건너뛰고 다음 선택 | 설명만 |
| `:s/a/b/g` | 현재 줄의 `a`를 전부 `b`로 치환 | 기본 형태는 같음. 정규식 문법 차이 주의 |
| `g /` | 프로젝트 전체 검색 | LazyVim `Space /`. Zed `Cmd+Shift+F`도 가능 |
| 검색 결과에서 Vim 편집 → `:w` | 멀티버퍼에서 원본 파일 수정·저장 | `menu.md`만 수정한 실습 완료 |
| 검색 결과에서 `Enter` | 해당 원본 위치 열기 | 검색 결과 문맥에서 사용 |

`g a`는 문자열까지 함께 바꿀 수 있다. 코드 심볼의 이름 변경은 `g r n`을 쓴다.

## Git — Z6 진행 중

아래는 **다음 실습용으로 기록된 키**다. 아직 과제 완료가 아니며, 실행 직전 설치 버전의 키맵을 재확인한다.

| 키 | 용도 | LazyVim 대응 / 상태 |
|---|---|---|
| `] c` / `[ c` | 다음 / 이전 변경 hunk | LazyVim `] h` / `[ h` |
| `d o` | 커서 위치의 diff 열기 | 실습 대기 |
| `d p` | 커서 위치의 변경 되돌리기 | 실습 대기. 실제 변경을 되돌리므로 대상 확인 |
| `g B` | blame hover | 실습 대기 |
| `Ctrl+Shift+G` | Git 패널 | 파일 하나만 stage·커밋하는 과제 대기 |

## 사용자 키맵·설정

### Windows에 등록됨 — 동작 확인 대기

`VimControl && !menu` 문맥으로 등록했다. **Mac 적용 여부는 확인되지 않았다.**

| 사용자 키 | 용도 | LazyVim 대응 |
|---|---|---|
| `Space Space` | 파일 찾기 | 같음 |
| `Space e` | 프로젝트 패널 | 같은 용도로 맞춤 |
| `Space /` | 프로젝트 전체 검색 | 같음 |

which-key는 Mac·Windows 모두 설정한 기록이 있으며, 팝업 표시 확인은 대기 중이다.

### Mac에 등록됨 — 동작 확인 대기 (2026-11-02)

- `Space Space`: 파일 찾기
- `Space e`: 프로젝트 패널로 포커스 이동
- `Space /`: 프로젝트 전체 검색
- 단독 `Space` 기본 이동은 해제: 조합 키를 기다리는 동안 안내 유지(사용자 동작 확인 완료)
- `Ctrl+h/j/k/l`: 왼쪽 / 아래 / 위 / 오른쪽 pane 이동
- `Space \|` / `Space -`: 좌우 / 위아래 분할

편집기의 일반 모드에서 메뉴가 닫혀 있을 때 적용된다. 사용자 요청으로 기존 설정 백업 후 등록했다.

### 아직 적용하지 않은 후보

- `jk`: 입력 모드에서 `Esc`
- `Ctrl+S`: 저장

위 후보는 현재 쓸 수 있는 키라고 가정하지 않는다. `default_mode: insert`도 논의만 한 설정 후보다.

### Windows에서만 설명한 키

| 키 | 용도 | 상태 |
|---|---|---|
| `Shift+Esc` | pane 확대 토글 | 동작 미확인. Mac 키로 안내한 것이 아님 |
