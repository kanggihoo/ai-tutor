## 프로필 (2026-10-23 평가)
- 수준: 기본 입문. 방향키 병행, 레지스터/윈도우/버퍼는 개념만 앎.
- 용도: Claude Code와 CLI 작업 → 파일 탐색, 값 수정, 코드 읽기/리뷰 위주. 직접 코딩은 적음.
- 이미 아는 것: 탐색기 `a d r m c H I y . <BS>`, `Space f f`, `Space f r`, `Space ,`, `G` `gg` `$`, `dd`, `u`. 모르는 것(필요할 때 끼워 넣기): 탐색기 `P`(미리보기) `Z`(전부 접기) `]g`/`[g`(git 변경 이동).
- 선호: 세션당 20~30분. 대화로 한 문제씩(문서를 직접 읽는 방식은 싫어함). **쉬운 키는 확인 질문 없이 빠르게 넘어가길 원함**(2026-10-26, AGENTS.md에 규칙 반영). "이걸 쓸 일이 있나?"를 자주 묻는 편이라 키마다 쓰임새를 한 줄로 함께 알려주면 좋음.
- 환경: nvim 0.12.4, LazyVim 16.0.1, Snacks Explorer+Picker, rg/fd/lazygit 설치됨(Mac 확인).

## 약점 (Weak spots)
- `gg`/`G`/`$`는 2026-10-26 드릴에서 모두 정답, `0`(맨 처음 칸)과 `^`(첫 글자)는 직접 눌러 구분함 → 거의 해소. 다음 세션 복습 퀴즈에 한 번만 더 확인하고 졸업. 연상법: `^`=정규식의 첫 글자, `$`=정규식의 끝.
- `^`는 `Shift+6`이라 손가락이 뻗는 게 불편하다고 함. 대안으로 `_`(Shift+`-`, 기본 매핑) 안내함. 레슨 4에서 `I`(첫 글자에서 입력 시작)를 알려줄 것.
- `dd`가 레지스터를 덮어써서 붙여넣기가 꼬이는 문제를 겪고 있음 → 레슨 6.
- 한글 입력 상태에서 일반 모드 키가 안 먹음 → 영문 전환 + Esc. 자동 전환 설정은 미적용.
- Herdr 패널 분할과 nvim 창 분할을 혼동한 적 있음.

## 확인한 진도 (2026-10-26 기준, Windows 세션)
"확인"은 사용자가 결과를 보고한 것, "설명만"은 안내했지만 실행 확인이 없는 것.

| 주제 | 키 / 개념 | 상태 |
| --- | --- | --- |
| 파일 찾기 | `Space Space`, 대안 `Space f f` | 확인 |
| 퍼지 검색 | `config`, `src config`, `srcconfig` | 확인. `src/config.js`는 안 나온다고 보고(원인 미확인) |
| 프로젝트 내용 검색 | `Space /` | `shippingFee` 검색 결과 확인 |
| 직전 버퍼 / 버퍼 목록 | `Space b b` / `Space ,` | 확인 |
| 이전/다음 버퍼 | `Shift+h` / `Shift+l` | 설명만 |
| 좌우 분할 / 창 이동 / 창 닫기 | `Space \|` / `Ctrl+h,l` / `Space w d` | 확인. 창을 닫아도 버퍼는 남음 |
| 버퍼 닫기 | `Space b d` | 설명만(창/버퍼 차이는 이해) |
| 같은 버퍼를 여러 창에서 | 버퍼 공유, 커서·스크롤은 창별 | 개념 확인 |
| 저장 | `Ctrl+s` | 확인(실제 저장은 미검증) |
| 현재 버퍼 검색 | `/config` → Enter, `n`/`N` | 확인 |
| 현재 파일 줄 목록 | `Space s b` | 설명만. `/`는 순회, `Space s b`는 목록에서 비교·선택 |
| 한 줄 / 여러 줄 주석 | `gcc` / `Shift+v` → `j` → `gc` | 확인(긍정 응답), `u`로 복원 |
| 단어·문자열 바꾸기 | `ciw` / `ci"` | 확인. `cw`는 현재 위치부터 단어 끝. `ciW` `ci'` `ci(` `ca"` `cc` `C` `ct,`는 설명만 |
| 줄 복사·붙여넣기 | `yy` → `p`, `P`는 위쪽 | 확인 |
| 잘라내기 | `dd`, 비주얼 선택 후 `d` | `dd` 보고함. 비주얼 `d`는 설명만 |
| 실행 취소·재실행 | `u` / `Ctrl+r` | 확인 |
| 창 확대·복원 | `Space w m` | 확인 |
| 위아래 분할 | Windows는 `Space -`가 Yazi라 `Ctrl+w s` 안내 | 건너뜀. `Ctrl+j,k` 이동 미확인 |
| 터미널 | `Ctrl+/` | Mac에서 열림 확인(2026-10-26). 터미널 안에서 다시 누르면 숨김, 편집 창에서 누르면 터미널로 이동(소스 확인 + 사용자 직접 확인 2026-10-26) |

파일은 디스크, 버퍼는 메모리의 편집 내용, 창은 버퍼를 보여주는 영역으로 설명함. 탭 페이지는 개념만. 별도 Herdr 패널의 nvim끼리는 버퍼를 공유하지 않음. 레지스터와 OS 클립보드 연결 설정은 조사하지 않음.

- 2026-10-26 (Mac): 두 프로젝트(nvim-tutor, lazyvim-practice)를 이 저장소로 통합. `AGENTS.md` 신설, `HANDOFF.md`는 이 문서와 AGENTS.md로 흡수. `Space -`는 Mac에서 위아래 분할, `Ctrl+/` 터미널은 열림·숨김 모두 사용자가 확인(터미널 안에서 누르면 숨김, 편집 창에서 누르면 터미널로 이동).
- 2026-10-26 (Mac, 레슨 2 완료): 드릴 `G` `$` `gg` 모두 정답. `$`는 논리 줄 끝(화면에서 접혀도 한 줄)이라고 설명. `0`/`^` 구분함. `Ctrl-d`=화면 절반(약 24줄), 정확한 줄은 `36G`. `w` 2번으로 `30` 도착(`:`가 별도 단어), `b` 확인. 70행 이동 과제는 결과 보고 없이 넘어감(미확인). `{ }` `zz`는 쓸 일이 적어 설명만. 상대 줄 번호는 LazyVim 기본값(`Space u L`로 토글)이라고 안내.
- 2026-10-26 (Mac, 레슨 3 시작): `*`는 `/`+커서 단어 자동 입력. 단어 경계 일치(`orders`는 `order` 검색에서 제외), `ignorecase` 때문에 대소문자 무시(`*`에는 smartcase 미적용). `/`는 소문자만 입력하면 무시, 대문자 포함 시 구분.
- 2026-10-27 (Mac): 저장소를 `ai-tutor`로 바꾸고 nvim 자료를 `nvim/`으로 옮김(`rust/` 과목 추가). `Space Space`는 git 루트 기준이라 rust 파일도 보임 → `Space f F`(cwd) 안내.
