## 프로필 (2026-10-23 평가)
- 수준: 기본 입문. 방향키 병행, 레지스터/윈도우/버퍼는 개념만 앎.
- 용도: Claude Code와 CLI 작업 → 파일 탐색, 값 수정, 코드 읽기/리뷰 위주. 직접 코딩은 적음.
- 이미 아는 것: 탐색기 `a d r m c H I y . <BS>`, `Space f f`, `Space f r`, `Space ,`, `G` `gg` `$`, `dd`, `u`. 모르는 것(필요할 때 끼워 넣기): 탐색기 `P`(미리보기) `Z`(전부 접기) `]g`/`[g`(git 변경 이동).
- 선호: 세션당 20~30분. 대화로 한 문제씩(문서를 직접 읽는 방식은 싫어함). **쉬운 키는 확인 질문 없이 빠르게 넘어가길 원함**(2026-10-26, AGENTS.md에 규칙 반영). "이걸 쓸 일이 있나?"를 자주 묻는 편이라 키마다 쓰임새를 한 줄로 함께 알려주면 좋음.
- 환경: nvim 0.12.4, LazyVim 16.0.1, Snacks Explorer+Picker, rg/fd/lazygit 설치됨(Mac 확인).

## 약점 (Weak spots)
- `gg`/`G`/`$`는 2026-10-26 드릴에서 모두 정답, `0`(맨 처음 칸)과 `^`(첫 글자)는 직접 눌러 구분함 → 거의 해소. 다음 세션 복습 퀴즈에 한 번만 더 확인하고 졸업. 연상법: `^`=정규식의 첫 글자, `$`=정규식의 끝.
- `^`는 `Shift+6`이라 손가락이 뻗는 게 불편하다고 함. 대안으로 `_`(Shift+`-`, 기본 매핑) 안내함. 레슨 4에서 `I`(첫 글자에서 입력 시작)를 알려줄 것.
- `dd`가 레지스터를 덮어써서 붙여넣기가 꼬이는 문제를 겪고 있음 → 레슨 6.
- 한글 입력 상태에서 일반 모드 키가 안 먹음 → 영문 전환 + Esc. 자동 전환 설정은 미적용.
- Herdr 패널 분할과 nvim 창 분할을 혼동한 적 있음.

## 확인한 진도 (2026-10-26 기준, Windows 세션)
"확인"은 사용자가 결과를 보고한 것, "설명만"은 안내했지만 실행 확인이 없는 것.

| --- | --- | --- |
| 파일 찾기 | `Space Space`, 대안 `Space f f` | 확인 |
| 퍼지 검색 | `config`, `src config`, `srcconfig` | 확인. `src/config.js`는 안 나온다고 보고(원인 미확인) |

파일은 디스크, 버퍼는 메모리의 편집 내용, 창은 버퍼를 보여주는 영역으로 설명함. 탭 페이지는 개념만. 별도 Herdr 패널의 nvim끼리는 버퍼를 공유하지 않음. 레지스터와 OS 클립보드 연결 설정은 조사하지 않음.
