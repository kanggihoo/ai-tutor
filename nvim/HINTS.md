# 힌트 — 아직 정답 키는 보지 않기

Esc로 일반 모드에 돌아오고 Space를 눌러 키 안내를 살펴보세요.

| 미션 | 찾아볼 기능 이름 |
| --- | --- |
| 01 | Find Files / files |
| 02 | Grep / Search |
| 03 | Explorer |
| 04 | Buffers / Switch to Other Buffer / Delete Buffer |
| 05 | Split Window Right / Delete Window. 창 이동은 Ctrl과 방향 문자 조합. |
| 06 | Split Window Below / Toggle Zoom Mode |
| 07 | Save File. 실행 취소와 재실행은 기본 Vim 조작. |
| 08 | Comment. 커서가 해당 줄 위에 있어야 합니다. |
| 09 | Buffer Lines. 전체 검색인 Grep과 구분하세요. |
| 10 | Terminal |
| 11 | 파일 찾기 + 전체 검색 + 창 분할 + 저장 + 버퍼 닫기 |
| 12 | 막혔던 기능의 메뉴만 다시 확인하세요. |

검색창에서는 이름 일부를 입력하고 방향키로 선택한 뒤 Enter로 엽니다.
탐색기 종류와 버전에 따라 폴더 펼치기 키가 다를 수 있습니다. 선택 후 Enter를 먼저 사용하세요.
