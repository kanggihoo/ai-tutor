# 레슨 03 빌림 (2026-10-28~29)

## 이론
- `&T` 읽기 빌림은 여러 개, `&mut T`는 동시에 하나. 둘은 섞이지 않는다.
- 빌림은 참조의 **마지막 사용 줄**까지만 산다(NLL).
- `String`(소유·수정)과 `&str`(읽기 뷰). 함수 인자는 `&str`. 슬라이스는 `&s[0..5]`로 원본 일부를 빌린다.
- 용어: **move**는 소유권을 넘김(원본 못 씀), **borrow**는 접근만 빌림(주인은 그대로).

```rust
let mut s = String::from("hi");
let a = &s;        // 빌림 시작
println!("{a}");   // 마지막 사용
s.push('!');       // OK
```

## 퀴즈
- `&` 두 개 후 `&mut`, 쓰는 중이면 E0502, `&mut` 두 개 동시 E0499.
- `&str`을 `&String` 자리에 넘기면 E0308. 복습 Q1(E0502 5번째 줄), Q2(E0308)도 정답.

## 실전
- 고치기 `lab/src/bin/03_borrow_q2.rs`, `03_borrow_q3.rs`, `03_str_q2.rs`, `03_str_q3.rs`
- 리뷰 `lab/src/bin/03_review_p1.rs`: 원래 `greet(&name.clone())`과 `name: &String`. 핵심은 `.clone()` 제거(읽기만 하니 빌림으로 충분), `&String` → `&str`.

## 틀린 것
- `&`를 "소유권 제공"으로 이해(용어 혼동). 슬라이싱 `&` 재질문 2회.
- `&str`을 `&String` 자리에 넘겨도 된다고 예측.
